SponsorBlock

Unchecking everything disables marking/removing entirely. "Mark only" categories are skipped for removal — yt-dlp doesn't allow cutting them.

Geo-restriction

yt-dlp fakes an X-Forwarded-For header where it's known to help (its default). Override that here.

Debug & Logging

Notifications

One notification per batch, not per video — with the count of finished/failed downloads, or the title when it's just one. Cancelled downloads don't count. macOS shows it via Notification Center; Linux needs notify-send.

Browser extension

Off: the URL lands in the box with a preview and you click Download. On: it goes straight into the queue with the current settings.
