Advanced options

Format & Quality

Remux and recode can't both apply; remux wins. Reach for recode only when the codecs themselves need changing.

Filename & Output

Click a field to insert it. A / makes a subfolder; widths and lengths work too, e.g. %(playlist_index)03d or %(title).60s.
Example
A long title plus a long template can exceed the filesystem's 255-byte limit, and the download fails at the very end when the file is moved into place.

Playlist

Re-running a channel or playlist then only fetches what's new. The skip list is built from the History tab (--download-archive), so removing an entry there — or clearing history — makes that video downloadable again. The preview marks already-downloaded videos and unticks them in the playlist picker.

Live Streams

Where the site keeps the earlier part of a stream available (YouTube usually does). Without it a live download starts at the current moment.
yt-dlp keeps polling until the stream starts instead of failing with "this live event will begin in…". The queue item just sits there running in the meantime.

Subtitles

Comma-separated, or all. Preview a video and its actual languages appear as buttons under the card.
YouTube serves vtt; most players and tools want srt.

Thumbnail & Metadata

YouTube serves webp, which many file managers and editors won't preview.

Audio Extraction

Network

How many queue items run at once — separate yt-dlp processes. Applies immediately. The rate limit below is the total, split across the downloads actually running.
Pieces of one video fetched in parallel. The big speed-up for YouTube (DASH/HLS); 4–8 is typical.
If YouTube slows a download below this, yt-dlp re-extracts and tries again.
Politeness for bulk runs — a random pause per download, and a pause before each metadata request.
For sites behind Cloudflare and similar. Needs a yt-dlp built with curl_cffi (the standalone binary is); yt-dlp --list-impersonate-targets shows what yours supports.

Authentication & Cookies

Without this, a multi-profile Chrome or Firefox hands over whichever account is the default — not necessarily the one you're signed in with.

SponsorBlock

Unchecking everything disables marking/removing entirely. "Mark only" categories are skipped for removal — yt-dlp doesn't allow cutting them.

Geo-restriction

yt-dlp fakes an X-Forwarded-For header where it's known to help (its default). Override that here.

Debug & Logging

When a site breaks, the fix often lands on nightly well before the next stable release. Only the standalone yt-dlp binary can switch channels — a Homebrew, pip or distro install follows whatever its packager ships.
Off by default: yt-dlp is run with --ignore-config so this app's settings are the whole story. Turn it on if you keep options in a yt-dlp config file — they'll merge with, and can override or double, what the panels say.

Appearance

Applies immediately. The window frame's own colour is picked when the app starts, so it catches up on the next launch.

Notifications

One notification per batch, not per video — with the count of finished/failed downloads, or the title when it's just one. Cancelled downloads don't count. macOS shows it via Notification Center; Linux needs notify-send.

Browser extension

Off: the URL lands in the box with a preview and you click Download. On: it goes straight into the queue with the current settings.
